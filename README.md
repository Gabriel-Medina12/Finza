# 🪙 Finza

**Finza** es una aplicación multiplataforma de finanzas personales diseñada bajo un enfoque de minimalismo premium y alto rendimiento. Su objetivo es brindar a los usuarios un control total, preciso e inmediato de sus ingresos, gastos y transferencias multimoneda en tiempo real con costo de infraestructura cero ($0).

### 🚀 Características Principales

*   **Soporte Multimoneda Inteligente**: Diseñada especialmente para el contexto financiero actual, gestiona saldos en **Bolívares (VES)**, **Dólares (USD)**, **Euros (EUR)** y **USDT (Cripto)** de forma unificada.
*   **Conversión Cambiaria Automática**: Sincroniza las tasas oficiales del Banco Central de Venezuela (BCV) y el mercado paralelo de USDT en tiempo real desde APIs públicas, actualizando el patrimonio neto consolidado al instante.
*   **Escáner de Facturas con IA**: Integra el modelo **Gemini 2.5 Flash Lite** para analizar fotografías de tickets o facturas, extrayendo de manera automática el comercio, el monto final, la divisa y sugiriendo la categoría de gasto apropiada.
*   **Diseño Oscuro Premium (UX/UI)**: Interfaz fluida, moderna y scannable inspirada en componentes glassmorphic, micro-animaciones interactivas y selectores adaptados para evitar desbordamientos en cualquier dispositivo móvil o de escritorio.
*   **Backend Servidor con Supabase**: Autenticación integrada (OAuth con Google y Correo/Contraseña) y almacenamiento seguro de datos mediante PostgreSQL protegido por políticas RLS (Row Level Security).
